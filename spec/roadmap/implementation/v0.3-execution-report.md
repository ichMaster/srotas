## Note for the real preview / calibration

The mocked tests verify the scoring + preview logic end to end. Calibrating the
0.35 threshold **by eye over the 619 real Guardian items** additionally needs a
Voyage key in `config.toml` (`[voyage] api_key`); then:

```
python -c "from core import pipeline, model; from core.config import load_config; \
  cfg=load_config(); pipeline.embed_and_score('items.sqlite', model.load_model(), \
  threshold=cfg.cosine_threshold, api_key=cfg.voyage_api_key)"   # backfill + score
python -m core.scoring --preview --threshold 0.35
```
